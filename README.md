# CONDOR · Entrega 2 (ING2030)

Presentación de la Entrega 2 del proyecto CONDOR, cortafuegos preventivo de suscripciones para la banca.

**En vivo:** https://nicolascovarrubias.github.io/condor-e2/

## Cómo presentar

- `→` / `Espacio`: siguiente lámina · `←`: anterior
- `F`: pantalla completa
- `N`: notas del presentador, con guion y tiempos
- `T`: reinicia el cronómetro de las notas
- `#n` en la URL abre directo la lámina n. `?static` muestra el estado final de cada lámina, igual que el PDF.

## PDF para Canvas

`E2 ppt-G68.pdf` es la exportación de este HTML, una lámina por página. Para regenerarlo con Chrome:

```
chrome --headless=new --no-pdf-header-footer --virtual-time-budget=6000 --print-to-pdf="E2 ppt-G68.pdf" index.html
```

También sirve imprimir desde el navegador (Ctrl+P → Guardar como PDF, márgenes: ninguno, con gráficos de fondo).

Los marcadores punteados en naranja son contenido pendiente del equipo.
